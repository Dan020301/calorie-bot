# 🥗 Calorie Bot — Telegram-бот для подсчёта калорий по фото

Бот распознаёт еду на фото через бесплатный API **Google Gemini**, считает
КБЖУ, ведёт дневник питания за день/неделю, дневник веса и отправляет
напоминания.

## Возможности

| Функция | Как пользоваться |
|---|---|
| 🎯 Норма калорий | При первом `/start` бот задаст несколько вопросов (цель, пол, возраст, рост, вес, активность) и рассчитает дневную норму по формуле Миффлина–Сан Жеора. Пересчёт — `/norm` → «🔄 Пересчитать» |
| 📸 Распознавание еды | Просто отправь фото блюда |
| 💬 Подпись к фото | Добавь текст к фото — бот учтёт пояснение при оценке («это на двоих», «порция большая») |
| ✍️ Подтверждение и правки | Перед добавлением бот спросит: добавить, исправить значения или отменить |
| 🗣 Правка своими словами | В правке можно просто написать замечание («рису было меньше») — ИИ пересчитает сам |
| 🎙 Голосовые сообщения | Наговори, что съел, — бот распознает речь и посчитает КБЖУ |
| 🍽 Еда текстом | `/eat два яйца и тост` |
| 🏷 Штрихкоды | Фото штрихкода с подписью «штрих» или `/barcode 4600682050079` — продукт из открытой базы Open Food Facts |
| 🔁 Съесть снова | После добавления еды бот предлагает кнопки с недавними блюдами — повтор в один тап |
| 📊 Итоги за день | `/today`: прогресс к норме, вода, стрик, распределение по приёмам пищи |
| 📈 Статистика за неделю | `/week` с наблюдениями (перебор/недобор/белок) |
| ⚖️ Дневник веса | `/weight 82.5`; `/weights` — график PNG с линией цели и прогнозом достижения целевого веса |
| 💧 Вода | `/water 250` или кнопки +250/+500; норма настраивается в `.env` (`WATER_NORM_ML`) |
| 🔥 Стрики | `/streak` — серия дней подряд с записями |
| 🏅 Топ продуктов | `/top` — что ешь чаще всего |
| 📄 Экспорт | `/export` — выгрузка дневника в CSV (открывается в Excel) |
| 🔔 Умные напоминания | `/remind on` / `/remind off`; текст зависит от прогресса за день |
| 🌆 Отчёт за день | Каждый вечер в `DAILY_SUMMARY_TIME` (по умолчанию 21:30) |
| 📅 Еженедельная сводка | Воскресенье в `WEEKLY_SUMMARY_TIME` (по умолчанию 20:00): средние, изменение веса, выводы |
| 📋 Сводка | `/status` |

## Структура проекта

```
calorie-bot/
├── bot/
│   ├── main.py               # точка входа: запуск polling + планировщик
│   ├── config.py             # настройки из .env
│   ├── scheduler.py          # напоминания, отчёты за день/неделю (APScheduler)
│   ├── handlers/
│   │   ├── start.py          # /start, /help, запасной обработчик текста
│   │   ├── photo.py          # фото/голос/штрихкод -> подтверждение -> дневник
│   │   ├── profile.py        # анкета, расчёт нормы калорий (/norm)
│   │   ├── stats.py          # /today, /week
│   │   ├── weight.py         # /weight, /weights (график + прогноз)
│   │   ├── water.py          # /water и кнопки быстрого добавления
│   │   ├── extras.py         # /top, /streak, /export
│   │   └── reminders.py      # /remind on|off, /status
│   ├── services/
│   │   ├── vision.py         # запросы к Gemini: фото, голос, текст, штрихкод
│   │   └── off.py            # Open Food Facts: продукты по штрихкоду
│   └── db/
│       └── database.py       # SQLite (aiosqlite): еда, вес, вода, профиль
├── requirements.txt
├── export_html.py             # HTML-отчёт по пользователям (python export_html.py)
├── .env.example              # шаблон настроек -> скопировать в .env
├── run_checks.py             # автопроверки (python run_checks.py)
└── README.md
```

## Хранение данных

Всё хранится локально в SQLite (`calories.db`) — никаких серверов и оплат.
Один пользователь = одна запись веса в день (повторная `/weight` обновляет её).

## Ограничения

- Оценки КБЖУ приблизительные: модель оценивает порции «на глаз» по фото.
